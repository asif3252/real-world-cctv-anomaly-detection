# Contributing

Open an issue with expected behavior, reproduction steps and Python/package versions. Remove passwords, authenticated RTSP URLs, NVR addresses and identifiable footage.

For changes, use a focused branch and explain the behavior being changed. Run `python -m unittest discover -s . -p test_events.py`. Add meaningful tests when rule behavior changes. Report performance with hardware, input size, camera count and measurement method.

Useful contributions include stream recovery, bounded buffering, tests and labeled evaluation. Avoid claims of production readiness without evidence.
